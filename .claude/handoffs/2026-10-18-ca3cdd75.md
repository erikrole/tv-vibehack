## Goal
Build a custom home-screen launcher for the Basement TV (Hisense), delivered as PR #1 in erikrole/tv-vibehack. Erik gives feedback in chat, and each round gets built on the emulator, pushed, and installed on the TV.

## Decisions (and why)
- **Hisense Menu key** is left alone. It opens the TV's own menu, which has a built-in Sleep Timer, so the launcher never receives it.
- **Control Center** opens only from the sliders pill. README updated to match.
- **Calmer motion:** Erik said the spring was too much. Tile overshoot went 1.6→0.5, tilt 7°→3°, glass highlight heavily damped, Control Center eases in.
- **Hero banner removed:** Erik said the icons were redundant.
- **Network icon follows the connection:** LAN icon for Ethernet, Wi-Fi icon for Wi-Fi, struck-through when offline.
- **Font changed from Outfit to Inter** (Erik approved). Apple's SF can't be bundled in an app. Wide-tracked ALL-CAPS labels replaced with sentence case.
- **Outline snaps to tile during Down scrolls** because the spring lagged behind the moving target. Sideways moves keep the spring.
- **Install uses `basement/install.sh --no-debloat`** so debloat settings stay unchanged.
