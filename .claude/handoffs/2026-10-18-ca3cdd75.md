## Goal
Build the Basement TV launcher, a home screen for the Basement Home Theater TV, and iterate on it from Erik's feedback. Work lives in PR #1 at https://github.com/erikrole/tv-vibehack/pull/1.

## Decisions (and why)
- **Peeking row hidden** until Down is pressed, because the next row showed at the bottom edge.
- **D-pad path:** Up from the dock goes to the scene chips, then the top-bar pills. Down from the pills returns to the chips. Previously the pills were unreachable.
- **Hisense Menu key left alone.** It opens the TV's own menu, which has a built-in Sleep Timer, so the launcher never sees it.
- **Control Center opens only from the sliders pill.** README updated to match.
- **Calmer motion** per Erik: tile overshoot 1.6 to 0.5, tilt 7° to 3°, glass highlight heavily damped, Control Center eases in.
- **Hero banner removed** as redundant.
- **Network icon follows the connection:** LAN for Ethernet, Wi-Fi icon for Wi-Fi, struck-through when offline.
- **Sentence case** replaces wide-tracked ALL-CAPS. Apple's SF font can't be bundled, so Erik approved Inter.
- **Install used `basement/install.sh --no-debloat`,** leaving debloat settings unchanged.
