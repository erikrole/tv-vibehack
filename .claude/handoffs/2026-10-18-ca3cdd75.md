## Goal
Basement lighting in Home Assistant should follow TV playback: Movie while something plays, Intermission when paused or stopped, and the Sensor Light when the TV is off. The work is tracked in the PR.

## Decisions (and why)
- **Own automation, not the add-on blueprint.** Erik's Home Theater Sensor Light automation already uses Blackshome's Sensor Light, and his media add-on isn't installed. Erik's existing `input_boolean.home_theater_bypass` does the job, so the new automation builds on it. Importing the add-on remains an option if Erik wants it.
- **Reused the existing scenes** Movie, Intermission and Lights Up, which flip the bypass so the Sensor Light doesn't fight them.
- **Playback reporting from the TV.** Home Assistant's TV entity only reports the open app and power state, so the launcher's `PlaybackReporter` service reads Android media sessions and sends playing/paused/stopped state to Home Assistant. Erik approved this with "build it."
- **Global light bypass is the kill switch.** The automation does nothing while it is on.

## Done
- Game Day scene added, with Badgers-red TV bias light, warm sconces and lamp, low cans, and bypass on.
